## Installation

<CodeTabs className="gap-0">

<TabsListInstallType />

<TabsContent value="cli" className="[&>figure]:mb-0">

```bash
npx shadcn@latest add @envindavsorg/theme-switcher
```

</TabsContent>

<TabsContent value="manual">

### installez les dépendances :

```bash
npm install next-themes @phosphor-icons/react motion clsx tailwind-merge
```

### ajoutez le helper :

<ComponentSource
  src="src/lib/utils.ts"
  title="lib/utils.ts"
  showLineNumbers
  collapsible={false}
/>

### Copiez et collez le code suivant dans votre projet :

<ComponentSource
  name="theme-switcher"
  title="components/ThemeSwitcher.tsx"
  showLineNumbers
/>

### Mettez à jour les chemins d'import de vos dépendances pour correspondre à la structure de votre projet et ainsi le faire fonctionner correctement.

</TabsContent>

</CodeTabs>
