# 1. Installation avec le CLI de shadcn/ui

Copiez la commande ci-dessous dans votre terminal afin d'installer le composant

```bash
npx shadcn@latest add @envindavsorg/apple-hello-effect
```

# 2. Installation manuelle

## (2.1) installez les dépendances :

```bash
npm install motion clsx tailwind-merge
```

## (2.2) ajoutez le helper **cn** :

<ComponentSource
  src="src/lib/utils.ts"
  title="lib/utils.ts"
  showLineNumbers
  noCollapsible
/>

## (2.3) ajoutez le code suivant :

<ComponentSource
  name="apple-hello-effect"
  title="components/AppleHelloEffect.tsx"
  showLineNumbers
/>

## (2.4) petite astuce :

Mettez à jour les chemins d'import de vos dépendances pour correspondre à la structure de votre projet et ainsi le faire fonctionner correctement.

# 3. Utilisation

```tsx
'use client';

import { AppleHelloEffect } from '@/components/apple-hello-effect';

const AppleHelloEffectDemo = () => (
	<div className="flex min-h-64 items-center justify-center">
		<AppleHelloEffect className="text-foreground" speed={0.8} />
	</div>
);

export AppleHelloEffectDemo;
```

# 4. Propriétés

| Prop                  | Type         | Default     | Description                                                                                               |
| --------------------- | ------------ | ----------- | --------------------------------------------------------------------------------------------------------- |
| `speed`               | `number`     | 1           | Un multiplicateur qui affecte la durée de l'animation. Des valeurs plus élevées ralentissent l'animation. |
| `onAnimationComplete` | `() => void` | `undefined` | Fonction de rappel déclenchée lorsque l'animation se termine.                                             |
