## Utilisation

Utilisez cet encodeur et décodeur Base64 gratuit pour passer facilement du texte brut aux chaînes encodées en Base64, et inversement.
Cet outil est parfait pour décoder les réponses d'API.
Aucune inscription nécessaire — collez simplement vos données et convertissez-les instantanément.

## Comment utiliser l'outil de décodage Base64 :

Vous pouvez utiliser cet outil pour décoder des chaînes encodées en Base64,
ou pour reconvertir un texte Base64 en sa chaîne binaire d'origine.
Collez simplement vos données et copiez le résultat.

## Cas d'usage :

- **Conversion de données :** Convertissez des chaînes de texte en leur forme binaire d'origine, utile pour traiter des données textuelles encodées.
- **Débogage :** Décodez des données Base64 lors du dépannage ou de l'analyse de ressources web.

## Utiliser Base64 en JavaScript :

En JavaScript, l'encodage et le décodage Base64 se font avec les fonctions natives **btoa** et **atob**, comme illustré ci-dessous :

```javascript
const text = "Hello, world!";
const encoded = btoa(text);
console.log(encoded); // Résultat: "SGVsbG8sIHdvcmxkIQ=="
```

```javascript
const encoded = "SGVsbG8sIHdvcmxkIQ==";
const decoded = atob(encoded);
console.log(decoded); // Résultat: "Hello, world!"
```

**btoa** n'accepte que les caractères Latin-1 : pour tout autre texte (un emoji, par exemple), encodez-le d'abord en UTF-8 avec **TextEncoder**, comme le fait cet outil.

## Utiliser Base64 en TypeScript (Node.js) :

En TypeScript avec Node.js, l'encodage et le décodage Base64 se font avec la classe native **Buffer**, comme illustré ci-dessous :

```typescript
const text: string = "Hello, world!";
const encoded: string = Buffer.from(text).toString("base64");
console.log(encoded); // Résultat: "SGVsbG8sIHdvcmxkIQ=="
```

```typescript
const encoded: string = "SGVsbG8sIHdvcmxkIQ==";
const decoded: string = Buffer.from(encoded, "base64").toString(
  "utf-8"
);
console.log(decoded); // Résultat: "Hello, world!"
```

## Utiliser Base64 en Rust :

En Rust, l'encodage et le décodage Base64 se font avec la crate **base64**, comme illustré ci-dessous :

```rust
use base64::{Engine as _, engine::general_purpose};

let text = "Hello, world!";
let encoded = general_purpose::STANDARD.encode(text);
println!("{}", encoded); // Résultat: "SGVsbG8sIHdvcmxkIQ=="
```

```rust
use base64::{Engine as _, engine::general_purpose};

let encoded = "SGVsbG8sIHdvcmxkIQ==";
let decoded = general_purpose::STANDARD.decode(encoded).unwrap();
let text = String::from_utf8(decoded).unwrap();
println!("{}", text); // Résultat: "Hello, world!"
```

Ajouter dans `Cargo.toml` :

```toml
[dependencies]
base64 = "0.21"
```

Ces fonctions facilitent l'encodage et le décodage directement dans votre code, pour un traitement et une transmission fluides des données dans les applications web et côté backend.
