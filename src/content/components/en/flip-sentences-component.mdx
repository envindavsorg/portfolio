## 1. Installation with the shadcn/ui CLI

Copy the command below into your terminal to install the component:

```bash
npx shadcn@latest add @envindavsorg/flip-sentences
```

## 2. Manual installation

### (2.1) install the dependencies:

```bash
npm install motion clsx tailwind-merge
```

### (2.2) add the **cn** helper:

<ComponentSource
  src="src/lib/utils.ts"
  title="lib/utils.ts"
  showLineNumbers
  noCollapsible
/>

### (2.3) create the array with the sentences you want to cycle through:

```ts title="sentences.ts" {2-5}
const EXAMPLE_SENTENCES = [
  "Imagine, code, create, inspire.",
  "Every little pixel counts!",
  "Every little detail counts!",
  "From concept to deployment!",
];
```

### (2.4) add the following code:

<ComponentSource
  name="flip-sentences"
  title="components/FlipSentences.tsx"
  showLineNumbers
/>

### (2.5) a little tip:

Update the import paths of your dependencies to match your project's structure so the component works correctly.

## 3. Usage

```tsx
"use client";

import { FlipSentences } from "@/components/FlipSentences";

<FlipSentences sentences={EXAMPLE_SENTENCES} />;
```
