## 1. Installation avec le CLI de shadcn/ui

Copiez la commande ci-dessous dans votre terminal afin d'installer le composant :

```bash
npx shadcn@latest add @envindavsorg/theme-switcher
```

## 2. Installation manuelle

### (2.1) installez les dépendances :

```bash
npm install motion next-themes @phosphor-icons/react clsx tailwind-merge
```

### (2.2) ajoutez le helper **cn** :

<ComponentSource
  src="src/lib/utils.ts"
  title="lib/utils.ts"
  showLineNumbers
  noCollapsible
/>

### (2.3) ajoutez le code suivant :

<ComponentSource
  name="theme-switcher"
  title="components/ThemeSwitcher.tsx"
  showLineNumbers
/>

### (2.4) petite astuce :

Mettez à jour les chemins d'import de vos dépendances pour qu'ils correspondent à la structure de votre projet et que le composant fonctionne correctement.

## 3. Utilisation

```tsx
"use client";

import { ThemeSwitcher } from "@/components/ThemeSwitcher";

<ThemeSwitcher />;
```
