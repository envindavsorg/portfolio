Repository root: `e2e/` (Playwright specs), `messages/` (`fr.json`, `en.json`),
`project.inlang/`, `public/` (including `sw.js` and `offline.html`), and the
configuration files listed in STACK.md.

## Directory Purposes

- **`app/(fr)`** is the canonical implementation. `app/en` holds thin pages that
  define English metadata and re-render the FR views with `locale="en"`. Changing
  behaviour means changing the FR tree.
- **`app/(llms)`** exposes the same content as raw markdown for AI ingestion and for
  the "Copy Markdown" button.
- **`components/base` and `components/primitives`** are the only places that touch
  Base UI directly.
- **`components/features`** holds everything specific to the writings pages
  (`Writings*`); `components/utils` holds one component per `/utils` tool.
- **`lib`** is for logic with no React and no filesystem coupling where possible —
  that is what makes it unit-testable.
- **`paraglide/` and `__registry__/`** are generated. Never edit them by hand.

## Naming Conventions

- Components: PascalCase files, named exports (`Panel.tsx` → `export const Panel`)
- Hooks: `useX.ts` in camelCase (`useMediaQuery.ts`, `useConfig.ts`)
- Server actions: `<name>.action.ts`
- Libraries: kebab-case (`feed-routes.ts`, `rate-limit.ts`)
- Tests: `<module>.test.ts` next to the module; e2e specs `<topic>.spec.ts` in `e2e/`
- Route groups in parentheses; private folders prefixed `_`
- Co-located static data in a `content.ts` beside the section that uses it

## Where to Add New Code

| Adding… | Goes in… |
|---|---|
| A homepage section | `app/(fr)/(content)/(root)/_components/<section>/`; wrap it in `SectionBoundary` + `Suspense` if it fetches remote data, as `Commits` does |
| A page | the FR tree first, then a thin `en/` counterpart |
| A `/utils` tool | logic in `src/lib/<tool>.ts` + test, UI in `src/components/utils/`, MDX in `src/content/utils/` (FR **and** `en/`), and register it in `src/components/markdown/mdx.tsx` |
| A UI primitive | `components/primitives/` (or `base/` when it wraps a Base UI part) |
| A server action | `src/actions/<name>.action.ts` |
| A reusable computation | `src/lib/<name>.ts` with a sibling test |
| A UI string | `messages/fr.json` **and** `messages/en.json` |
| An env variable | `src/env.ts` only |
| A distributable component | `src/registry/`, then `pnpm registry:build` |

## Special Directories

- `src/paraglide/` — generated, git-ignored. `pnpm i18n:compile` rebuilds it; it must
  exist before `pnpm types` on a fresh clone.
- `src/__registry__/` — generated by `pnpm registry:build`.
- `public/images/` — partly generated by the `pnpm capture:*` scripts.
- `test-results/`, `playwright-report/` — Playwright artefacts, git-ignored.
- `.planning/` — these documents. Tracked by git despite a stale `.gitignore` entry.
